# Bundled font notices

VERIDIA self-hosts the following unmodified variable web fonts through
Fontsource 5.3.0 so builds and installed applications do not require Google
Fonts network access:

- Inter — Copyright 2016 The Inter Project Authors
- Manrope — Copyright 2019 The Manrope Project Authors
- Noto Sans SC — Copyright Google Inc.
- Noto Serif SC — Copyright Google Inc.

All four fonts are distributed under the SIL Open Font License 1.1. The full
license text is included in `OFL-1.1.txt`. Font files are emitted into the
application's local Next.js static assets during the build; they are not
modified by VERIDIA.
