# 表格模板与腾讯文档兼容

VERIDIA 1.0.2 的表格导入、模板下载和审核结果导出由规则包中的
`importExportTemplates` 配置驱动。配置可更新字段显示名、别名、必填字段、
列顺序、示例和本地数据源预设；配置会随 `jd-pages/veridia-rules` 的规则 ZIP
一起接受文件大小、SHA-256 与 Ed25519 签名校验，并在同一个 SQLite 事务中
启用。同步失败时继续使用旧模板；旧规则包未包含模板时使用内置默认模板。

当前支持本地 `.xlsx`、`.xls` 和 UTF-8 `.csv`，也支持把腾讯文档导出的
Excel/CSV 当作本地文件处理。文件、预览内容、笔记链接和审核结果不会上传。

`TENCENT_DOCS_ONLINE_LINK` 目前只有类型和适配器接口预留。腾讯文档在线读取、
授权与结果回写属于未来的软件功能更新，不属于规则包远程更新能力。规则包只能
更新字段映射、模板、别名、必填字段和导出格式，不能新增真实在线 API 调用逻辑。
未来实现后应通过 VERIDIA 软件自动更新覆盖安装，继续复用本地账号、数据库、
审核记录、小红书会话和规则，不要求用户卸载重装。

内置模板配置位于 `rules/default-import-export-templates.json`。

规则发布脚本通过 `exportCurrentRulePayload` 自动把当前模板配置写入
`rules.json`，并在 `manifest.json` 写入 `templateVersion` 和
`templateConfigSha256`。发布前校验会拒绝别名冲突、未定义必填字段、非法列顺序
和未知数据源预设。规则签名继续只使用 `VERIDIA_RULES_SIGNING_KEY_PATH`，不得
使用账号签名私钥。
