# VERIDIA 本地账号开发者说明

VERIDIA 账号完全离线签发和验证。账号、密码哈希及会话只保存在用户本机；账号工具不会访问网络。

## 首次初始化签名密钥

在开发电脑的项目目录运行：

```powershell
npx.cmd tsx scripts/account-developer-tool.ts init-key
```

默认私钥保存在：

`%LOCALAPPDATA%\VERIDIA-Developer-Secrets\account-signing-ed25519-private.pem`

公钥保存在：

`config/account-signing-ed25519-public.pem`

如需更改私钥路径，只在开发电脑设置环境变量 `VERIDIA_ACCOUNT_SIGNING_KEY_PATH`。私钥必须离线备份，不得提交 GitHub 或复制到普通客户端。私钥丢失后，已签发激活码仍可由原公钥验证，但无法继续签发同一账号体系的新代码。

## 日常签发

- 双击 `创建VERIDIA账号.bat` 创建紧凑版 `VRD2` 账号激活码。创建时不输入初始密码；
  用户验证激活码后在自己的 VERIDIA 激活页面设置本地登录密码。
- 双击 `创建VERIDIA密码重置码.bat` 创建短期密码重置码。
- 双击 `创建VERIDIA账号更新码.bat` 修改既有账号的显示名称、角色或有效期。

`VRD2` 激活码只包含经过 Ed25519 签名的账号、显示名称、角色和有效期等授权信息，
不包含明文密码或 `passwordHash`。账号工具将激活码输出到当前开发者窗口并复制到剪贴板，
不落盘、不上传。操作完成后应清空剪贴板。客户端继续兼容已有的 `VRD1` 激活码。

## 纯离线方案限制

激活码不绑定硬件。同一激活码可能在其他电脑使用，客户端只能判断其是否已在当前数据库中使用。系统无法远程停用账号、查看账号使用情况或直接修改另一台电脑的本地密码。
